# 🧰 Fabry Toolbox

Raccolta di utility PowerShell per Windows, focalizzate su automazione e semplicità d'uso.

## 🎵 Audio
- **[MP3_Normalizza](https://github.com/fabrytoolbox/MP3_Normalizza)** — Normalizzatore EBU R128 con dry-run, log ed esclusioni.
- *(in arrivo)* **Video Scene Splitter** — Estrae scene da video usando FFmpeg.

## 🖥️ Sistema
- **[MATRIX_HOSTS](https://github.com/fabrytoolbox/MATRIX_HOSTS)** — Gestione file hosts con GUI Matrix, validazione e backup.

## 🖥️ Video
- **[Fabry-Frame-Extractor](https://github.com/fabrytoolbox/Fabry-Frame-Extractor)** - Converte video in singoliframe con upscale.

## 📬 Contatti
- Per segnalazioni o idee, apri una **Issue** nel repository di riferimento.
