# 🧰 Fabry Toolbox

Raccolta di utility PowerShell per Windows, nate da bisogni reali, focalizzate su automazione e semplicità d'uso: 
software commerciale troppo caro, o nessuna soluzione disponibile.

Da oggi le condivido perché so che altri hanno lo stesso problema.

## 🎵 Audio
- **[MP3_Normalizza](https://github.com/fabrytoolbox/MP3_Normalizza)** — Normalizzatore EBU R128 con dry-run, log ed esclusioni.
- **[Audio-Silence-Tools](https://github.com/fabrytoolbox/Audio-Silence-Tools)** — Rileva e toglie i silenzi in testa e coda degli MP3

## 🖥️ Sistema
- **[IsoMounter-Matrix]( https://github.com/fabrytoolbox/IsoMounter-Matrix)** — Monta e smonta ISO con GUI Matrix, log e pulizia automatica
- **[Norton-NIS-RAM-Monitor](https://github.com/fabrytoolbox/Norton-NIS-RAM-Monitor)** — Monitora il consumo di RAM dei processi di Norton Internet Security
- **[System-Sentinel-Matrix](https://github.com/fabrytoolbox/System-Sentinel-Matrix)** — Task Manager Matrix con protezione processi critici
- **[Subst-Manager](https://github.com/fabrytoolbox/Subst-Manager)** — GUI per gestione comando Subst con persistenza all'avvio
- **[App-Uninstaller-Tool](https://github.com/fabrytoolbox/App-Uninstaller-Tool)** — Disinstallatore robusto con Ghost Hunter, Deep Scan, GUI Matrix e CLI
- **[SmartFolder-Archiver](https://github.com/fabrytoolbox/SmartFolder-Archiver)** — Sistema per Backup di cartelle full/incrementale con 7zip con Gui Matrix
- **[RestorePoint-Manager](https://github.com/fabrytoolbox/RestorePoint-Manager)** — Gestione avanzata dei punti di ripristino Windows con GUI Matrix
- **[Spotlight-Reset](https://github.com/fabrytoolbox/Spotlight-Reset)** — Resetta la cache di Windows Spotlight e riavvia Esplora risorse
- **[Win11-Start-Repair](https://github.com/fabrytoolbox/Win11-Start-Repair)** — Ripara i componenti di Windows e registra i pacchetti AppX (menu Start)

### 🌐 Rete
- **[NetAdapter-Manager](https://github.com/fabrytoolbox/NetAdapter-Manager)** — Gestione avanzata delle schede di rete IP, DNS, DHCP; SubNet Mask e Gateway
- **[MATRIX_HOSTS](https://github.com/fabrytoolbox/MATRIX_HOSTS)** — Gestione file hosts con GUI Matrix, validazione e backup.

## 🖥️ Video
- **[Fabry-Frame-Extractor](https://github.com/fabrytoolbox/Fabry-Frame-Extractor)** - Converte video in singoli frame con upscale.
- **[Fabry-MKV-Converter](https://github.com/fabrytoolbox/Fabry-MKV-Converter)** - Converte video MKV a MP4 o da H265 a H264
- **[Video-Scene-Splitter](https://github.com/fabrytoolbox/Video-Scene-Splitter)** - Estrae scene da video con GUI Matrix, auto-FFmpeg
- **[Video-joiner](https://github.com/fabrytoolbox/Video-Joiner)** - Unisce video con FFmpeg, filtri, NVENC e GUI Matrix
- **[Video-From-Frames](https://github.com/fabrytoolbox/Video-From-Frames)** - Crea un video da una sequenza di frame JPG/PNG
- **[Video-Upscaler](https://github.com/fabrytoolbox/Video-Upscaler)** - Converte e fa upscaling di video con FFmpeg (NVENC o CPU)
